# Contract: KAAN art assets and generator

## Source

`art/kaan-splash-screen.jpg`: 1696 × 2528 px; white top-view KAAN silhouette with the word "KAAN", on black.
Provided by the wearer. Committed as the single source of truth.

## Generator: `tools/gen_kaan_art.py`

```text
python tools/gen_kaan_art.py [--emblem-aircraft-only]
```

- Windows only (like `gen_audio.py`). Decodes and resamples through PowerShell / .NET `System.Drawing` (bicubic,
  built into Windows). No third-party packages.
- Steps:
  1. luminance;
  2. bounding box of pixels with luminance > 48;
  3. 4 % margin, clamped to the image;
  4. crop;
  5. resize to the target sizes below (proportions kept);
  6. luminance → A8 (black point 16, white point 235, then clamped).
- Targets (Ultra 410 × 502; computed in the tool from the screen size and the corner radius 64). The tool is
  deliberately Ultra-specific (a dev tool, outside the firmware's layout code); another screen needs a re-run with its
  size. The firmware still positions the emblem from `PfdLayout` and shows it only where the box fits:
  - splash: fit inside 410 × 502 with a corner-safe margin (each α > 0 pixel inside the rounded rectangle; the tool
    checks this);
  - emblem: height = the Ultra emblem box height from `PfdLayout` (≈ 78 px), width by aspect (the tool uses the
    same formula and asserts it).
- `--emblem-aircraft-only`: crops the emblem to the aircraft only (excludes the "KAAN" lettering column). Use it only
  if the wearer finds the lettering illegible at emblem size.
- Deterministic: the same input gives byte-identical output.

## Output: `src/assets/KaanArt.h` / `src/assets/KaanArt.cpp` (generated, committed)

```cpp
// GENERATED by tools/gen_kaan_art.py from art/kaan-splash-screen.jpg. Do not edit.
#include "core/AlphaArt.h"           // struct AlphaArt { uint16_t w; uint16_t h; const uint8_t* a8; };
extern const AlphaArt kKaanSplash;   // full-screen splash
extern const AlphaArt kKaanEmblem;   // PFD emblem
```

- Arrays are `const` (flash, not RAM).
- The header comment records the source size, the crop box and the target sizes.
- `src/assets/` is data only: no Arduino or LVGL includes, so it compiles in the native tests too.
