# Data Model: KAAN Splash Screen and Watch-Face Emblem

## AlphaArt (type in `src/core/AlphaArt.h`; instances generated in `src/assets/KaanArt.{h,cpp}`)

The struct lives in a tiny core header, so `IBoard`, `core::SplashCompose`, `PfdPage` and the generated file all
share it without the board depending on the generated asset unit.

| Field | Type | Notes |
| :-- | :-- | :-- |
| `w`, `h` | `uint16_t` | pixel size |
| `a8` | `const uint8_t*` | `w × h` bytes, row-major, 0 = black/transparent, 255 = full white; in flash (rodata) |

Two instances: `kKaanSplash` (≈ 300 × 470, fits 410 × 502 minus the corner-safe margin) and `kKaanEmblem`
(≈ 48 × 74, the Ultra emblem box). Both are cropped from the same source with the same 4 % margin, so the emblem is
an exact downscale of the splash. Generated by `tools/gen_kaan_art.py`; never edited by hand
([contracts/art_assets.md](contracts/art_assets.md)). The sizes are computed for the Ultra screen (410 × 502, corner
radius 64); another screen needs a re-run with its size.

**Validation (generator + unit test):** `w × h` equals the array length; the size fits the target box; the
proportions match the source crop within 1 px.

## SplashSpec (passed from `main` to the board before `begin()`)

| Field | Type | Notes |
| :-- | :-- | :-- |
| `art` | `const AlphaArt*` | `nullptr` → no splash |
| `fg565` | `uint16_t` | colour (day: white `0xFFFF`; NVG: `core::NvgColor::toGreen565(0xFFFF)`) |
| `brightnessPct` | `uint8_t` | the stored brightness, or 10 % in NVG (same rule as `applyBrightness()`) |

**Show rule (BoardUltra, research R3; pure predicate `core::SplashCompose::shouldShow`):**
`art != nullptr` ∧ boot mode Normal ∧ `wakeCause == PowerOn`. Every other wake cause (`Button`, `Imu`, `Timer`, and
`Other` = an unmapped deep-sleep cause) gives reason `wake`; Safe/Headless gives `safe`; no art gives `none`. If the
PSRAM strip buffer cannot be allocated, BoardUltra reports `nomem`.

## SplashCompose (pure core, `src/core/SplashCompose.{h,cpp}`)

`row(a8, aw, ah, W, H, y, fg565, swap, out[W])` (raw mask pointer and size, so core needs no asset): the A8 mask is centred (`x0 = (W − w)/2`,
`y0 = (H − h)/2`); pixels outside the mask are black; inside, each channel is `fg × α / 255` (rounded), packed to
RGB565 and byte-swapped if asked.

**Invariants (tests):**
- α = 0 → `0x0000`; α = 255 → `fg`.
- Monotonic in α.
- A row outside the art is all black.
- The art is centred (off by at most 1 px for odd differences).
- `fitsRounded(a8, aw, ah, W, H, r, margin)`: every pixel with α > 0 lies inside the rounded screen rectangle (corner radius r).

## SplashResult (board → app, reported by `ad boot`)

| Field | Type | Notes |
| :-- | :-- | :-- |
| `shown` | `bool` | the splash was pushed |
| `atMs` | `uint32_t` | `millis()` when the last strip was pushed and the backlight set |
| `costMs` | `uint32_t` | compose + push time |
| `skip` | enum | `None`, `Wake`, `Safe`, `NoArt`, `NoMem` |

## PfdLayout.emblem (pure core, `src/core/PfdLayout`)

New `Box emblem`, computed with the portrait layout:

| Rule | Value |
| :-- | :-- |
| top | `rowY` (the ZULU/LOCAL row) |
| height | `h − m − rowY` |
| width | `round(height × aspect)` with `aspect = kKaanEmblem.w / h`, passed in as a parameter (core does not include the asset) |
| cap | if `width > contentW / 4`: width = `contentW / 4`, height = `round(width / aspect)` |
| x | `(w − width) / 2` |
| landscape / square | `{0,0,0,0}` (no gap; not drawn) |

**Invariants (tests, Ultra 410 × 502 r = 64):**
- non-empty;
- centred (±1 px);
- inside the screen, and every corner inside the rounded rectangle;
- no overlap with the ZULU/LOCAL text areas (box centre ± 55 px);
- no overlap with `eicas`, `adi` or the tapes.

For S3 240 × 240: empty.
